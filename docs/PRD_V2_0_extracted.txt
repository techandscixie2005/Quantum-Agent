1. 产品执行摘要
Quantum Agent 不是一个“量子物理聊天机器人”，也不是替学生完成作业的自动解题器。它是一套课程内教
学基础设施：课程材料决定知识边界，教师决定教学政策，确定性工具裁决可验证科学结论，LLM 只在受控节
点内承担诊断、解释、提问和教学化表达。
产品公式
Quantum Agent = 课程知识模型 + 课程知识图谱 + 教学计算图 + 学生学习证据 + 科学验证工具 + 计算实验环
境 + 教师治理系统

• 问概念：课程 grounding、概念联系、误区与迁移检查；
• 看推导：识别目标、定位第一处实质错误、给最小修正提示；
• 做实验：预测 -> 仿真 -> 验证 -> 解释 -> 迁移；
• 做项目：以 milestone 为状态单位，限制 Agent 只辅导当前可解锁步骤。
比赛演示仍围绕“量子隧穿与波包传播”黄金闭环，但 V2.0 必须额外显式展示：知识图谱证据、Policy Gate、
Verifier、LangGraph checkpoint、TA interrupt/resume、以及单/多智能体对照评测结果。

2.3 为什么采用 LangGraph，但不采用“Agent swarm”
LangGraph 在本项目中的价值是 durable state、checkpoint、interrupt/resume、subgraph 和可观测图运
行，而不是让多个角色自由互相聊天。根图由应用代码控制；专业 Agent 只作为节点或子图嵌入。
• 确定性流程优先：权限、政策、工具、引用、状态写入和升级规则都由代码执行；
• 上下文隔离：不同 specialist 只读取完成职责所需的最小状态；
• 人工可中断：关键教学/审核节点可以暂停并由 TA/教师恢复；
• 可证伪：若多智能体不能显著改善诊断、引用或恢复能力，则回退到更简单架构。

7.2 挫败处理
• 连续失败或反复请求同一提示时，首先降低任务粒度，而不是机械重复追问；
• 从苏格拉底追问切换到局部示范或前置知识回顾；
• 若仍无进展，触发 TA interrupt；
• “frustration”可以由 LLM 辅助识别，但升级阈值由 deterministic rule 决定。

• LLM 提取 assertion 默认 REVIEW_REQUIRED；只有教师审核或 deterministic 结构关系可进入 APPROVED；
• 学生查询仅返回 PUBLISHED document + APPROVED assertion。

7. 故意触发一个需要 TA 的条件（例如来源冲突或重复失败），展示 LangGraph interrupt。
8. TA 在教师端查看证据、诊断、Policy、工具轨迹，选择“编辑并恢复”；原 thread 继续执行。
9. 教师修改某计分作业最大提示 H4 -> H2；学生再次询问，Policy Gate 自动降级模型请求。
10. 最后展示 B0-B4 评测表：说明哪些 Agent 真正带来收益，哪些被保留/删除。
演示只讲一个故事：不是“我们用了多少 Agent”，而是“系统如何在课程证据、教学政策、科学验证和教师控
制下帮助学生完成一次真实学习闭环”。

28. Definition of Done
• Docker Compose 一键启动；无硬编码 API Key；
• 学生 / TA / 教师 / Admin 权限隔离，跨课程数据泄漏为 0；
• 课程知识图谱可由教师审核、发布，学生所有事实性课程回答可回到来源；
• 关键课程主题具有 SUFFICIENT narrative evidence，不能因可避免的数据缺口长期 model_degraded；
• 现有单智能体 10-step 行为已无回归迁移到 LangGraph；
• PostgreSQL checkpointer 可在服务重启/人工暂停后恢复 thread；
• 至少一个 TA interrupt/resume 流程真实 E2E 通过；
• Policy Gate、RBAC、Verifier、sandbox、citation contract 全部仍由代码强制；
• Evidence Agent 与 Diagnosis Agent 有离线指标证明价值；任何无收益 Agent 已删除或禁用；
• 至少 5 类 verifier 可运行，inconclusive 不被模型改写；
• 隧穿 Project 从预测到迁移题完整运行，其他 3 Project 可展示并启动；
• 教师可回放完整 graph trace，并查看误区、提示依赖、工具、interrupt；
• 黄金闭环 E2E 100%，interrupt/resume E2E 100%，live infra smoke 通过；
• 所有数据库迁移可执行并提供 downgrade；
• README 可让新机器部署；Release 保存评测报告、演示脚本、架构说明、安全说明与备份；
• 无伪造引用、无自动替学生提交作业、无把“多智能体”本身当成功指标。

附录 A. Codex 实施硬约束（摘要）
• 先做 behavior-preserving migration，不重写可工作的知识/政策/验证代码；
• LangGraph 是 runtime，不是让模型接管路由的理由；
• Agent 只允许 Evidence、Diagnosis、Tutor/Teacher Intelligence 等高认知职责；

• 每个 agent/subgraph 只获得最小必要 context；
• 每个 interrupt 前的 side effect 必须幂等；
• 保留 B0 baseline，并持续运行架构消融；
