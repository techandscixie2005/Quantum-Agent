# Teacher rubric anchors and contrasting scientific examples

**UNREVIEWED. TEACHER ONLY.** The examples below were authored for this heldout packet after the recorded fixed model runs. They were not used to tune those prior prompts. They are assessment-design examples, not student quotations, teacher endorsements or validated measurement instruments. Do not send them to the tutor before heldout evaluation.

For each selected question, record an explanation rating `meets`, `partial`, `needs_revision` or `not_assessed`, plus a separate numeric check `correct`, `incorrect`, `not_assessed` or `not_required`. Cite the student's actual line(s) and state a reason. Use `not_assessed` when the requested judgment lacks an assessable argument or an adequate reference; do not manufacture an error diagnosis. An unsupported runtime calculation cannot supply a numeric verdict, but a teacher may assess the student's work using the independently reviewed derivation/reference instead. A wrong explicit assertion supports `needs_revision` on the relevant criterion. A blank or bare number does not demonstrate a mechanism. Do not automatically replace all `not_assessed` responses by zero in a total score; predeclare a missing-data rule and report its consequences separately.

## Explanation anchors

| Packet criterion | Question | Meets | Partial | Needs revision | Not assessed |
|---|---:|---|---|---|---|
| HP1 Conditional sub-barrier trend | 1 | Fixed E,V0,m imply fixed κ and 1/κ; increasing a increases κa and lowers T | Correct direction and a plausible attenuation argument, missing a condition or scale distinction | Explicitly claims width changes κ/decay length, loses energy, or removes all transmission | Direction/number alone without an assessable mechanism |
| HP2 Matching and current | 2 | Nonzero two-exponential interior, four interface conditions, and current-ratio definition with exterior assumptions | Some correct relations but incomplete links | Forces ψ to zero from E<V0, or calls local density T | No meaningful derivation or definition |
| HP3 Threshold reasoning | 3 | Linear interior or controlled limit gives finite threshold T; separates physics from numerical refusal | Correct linear solution or limit setup, unfinished matching | Declares rejection proves zero or perfect T; uses a singular expression as a result | No assessable threshold work; outside taught syllabus is recorded, not blamed on a deficit |
| HP4 Above-barrier scope | 4 | Correct sin² dependence/resonance and nonmonotonic width comparison under stated assumptions | Recognizes interference/resonance but incompletely applies it | Universal “above means T=1” or universal decreasing width trend | Bare values without the required scope argument |
| HP5 Unequal asymptotic currents | 5 | Derives kR/kL factor from currents, converts trial amplitude, distinguishes trial from solved amplitude | Correct factor but incomplete physical account or arithmetic | Uses modulus squared alone despite unequal velocities; treats hypothetical input as solved T | No assessable current argument |
| HP6 Numerical reliability | 6 | Distinguishes physical positive T, representable tiny T, formatting/underflow, support bounds; proposes independent/relative/log checks | Correct distinction with an incomplete validation plan | Certifies exact zero from a printed zero or relies only on loose absolute agreement | Unsupported numerical result with no reasoning; no adequate reference available |
| HP7 Physical scales | 7 | Correct κ, 1/κ and a dependence; distinguishes changing energy from changing width | Corrects a term but leaves dependence implicit | Explicitly says 1/κ grows solely with width | No explanation to assess |
| HP8 Evidence and inference | 8 | Separates constructed conservation, independent numerical checks, independent submission conditions and explanation/teacher judgment | Identifies some boundaries but conflates others | Calls identity conservation independent validation, or calls one correct number demonstrated mastery | No assessable validation/inference argument |

The eight criteria are not equal-interval psychometric scores. If a teacher needs a numeric coding scheme, predeclare a descriptive 0–2 coding (`needs_revision=0`, `partial=1`, `meets=2`) and leave `not_assessed` separately coded. Publish criterion distributions and missingness before any aggregate. A change score is interpretable only for matched questions, comparable conditions and a declared scoring rule; it does not establish that this intervention caused the change.

The runtime design maps HP1/HP6/HP7 mainly to FB-R3, HP2/HP5 to FB-R2, the forbidden-region part of HP2 to FB-R1, and independent response conditions plus HP8 to FB-R4. HP3 and HP4 are explicit extension domains. Do not enter HP identifiers into an API that accepts only the pinned package's FB rubric identifiers. Record the detailed paper/JSON coding with the packet manifest digest, then let the actual teacher make any separately attributed FB rating. The rubric does not require teachers to endorse the packet or to rate an untaught extension as a student failure.

## Contrasting responses for scientific review

| Example | Authored response | What can be concluded |
|---|---|---|
| X1 Correct trend with a changed physical scale | “It goes down; the barrier gets wider, so the characteristic e-fold decay length increases.” | Direction correct, explanation needs revision. Fixed defining parameters make 1/κ fixed. Do not reward the mechanism because the sign is right. |
| X2 Width versus distance | “The same e-fold scale applies over a larger full width, so κa grows.” | Valid conditional mechanism for the sub-barrier task. Ask for current/matching only on criteria that require them. |
| X3 Number with no reasoning | “T=0.072499631760.” | Numeric A1-wide check can be correct; HP1/HP2 explanation is not assessed. A valid locked first submission does not fill in missing physics. |
| X4 Number with an incompatible explanation | “T=0.072499631760, because the interior wave function is exactly zero.” | Numeric value matches but the explicit zero-wave-function mechanism needs revision. Neither a numeric pass nor a completed app loop establishes mastery. |
| X5 Honest uncertainty | “I do not know how to connect the interface amplitudes to a current.” | An independent submission may be valid. HP2 is not assessed; this exact statement can guide a concrete probe, but it is not proof of every prerequisite deficit. |
| X6 Threshold workaround | “The calculator refused E=V0, therefore quantum theory says T=0.” | Needs revision on HP3: unsupported implementation is not a physical conclusion. The linear interior solution supplies the limit. |
| X7 Above-barrier interference | “At qa=π the two-interface matching gives T=1; at qa=π/2 it is smaller. Increasing width can therefore increase T.” | Valid for the listed symmetric above-barrier case. Do not generalize resonance unity to arbitrary asymmetric or absorbing barriers. |
| X8 Asymptotic normalization | “The right-side wave is slower, so T=(kR/kL)|t|², not just its squared amplitude.” | Correct current-ratio argument for constant mass, both exterior channels propagating and incident amplitude 1. |
| X9 Constructed conservation | “I set R=1−T; the error is zero, so the formula must be exact.” | Needs revision on HP8 even if this particular T is accidentally right. |
| X10 Misleading near-zero agreement | “Reference T≈10⁻⁴⁵ and my T=0 differ by less than 10⁻⁶; therefore both are verified.” | Needs revision on HP6. A relative positive-T comparison rejects zero; a runtime outside its scope should instead be inconclusive. |
| X11 A valid change in decay length | “At fixed V0 and mass, raising E toward V0 lowers κ and increases 1/κ.” | This parameter statement is correct. Do not reject the words ‘increases decay length’ without checking which parameters change. |
| X12 Feedback-supported revision | “After viewing feedback I replaced zero by the reference value.” | Preserve the first response and the revision. The revision can pass a numeric check but is not a fresh independent first performance. |

For any model-produced rating, a teacher must check the original answer, the correct parameter variation, the applicability of the source formula, and whether the rating is a local task judgment or a broader claim. Retain disagreement and its reason. Do not silently edit the model output or the student's initial answer to make an evaluation pass.
