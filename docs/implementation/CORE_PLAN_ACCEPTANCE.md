## 本轮完成的工程工作

- **结构化推导桥**：前后端新增起止式、中间步骤、定义、假设、前置知识、适用条件、原文引用合同与可展开界面。每条引用对齐到已发布证据的真实字符区间；question-only/hint 不释放桥，scaffold 最多一步，Solo 不显示。生成推导始终标为未验证模型推理，不能冒充教师审核结论。真实模型曾生成通过合同与引用检查的桥；最终复测的引文改写被拒绝并降级（见下表）。不支持的伴随事实声明会被移除并记录警告。
- **教学图谱管线**：新增 DerivationStep / Assumption / ValidityCondition 类型、关系约束及 `0008` 迁移。`extract-pedagogy` 从课程原文抽取候选、绑定精确引文、保留失败记录和教师已有决定；没有自动审批或发布。实际生成 140 个候选节点支持记录、51 条关系支持记录，详见[教师审核包](CORE_PLAN_TEACHER_REVIEW.md)。
- **课程证据相关性**：检索排除知识点导出表、教学大纲、目录及参考书列表，引入中英文课程术语匹配与逐项词法评分；保留已审核图谱的导航上下文，但不把结构性条目当教学原文。真实隧穿、完备性、光谱查询已返回教材/讲义正文。当前本机语义通道报告 `local_hashing_is_lexical` 降级，不能把这些结果当成真实语义向量检索验收。关键词相关性也不证明语义支持或覆盖完整。
- **多模态恢复**：视觉请求共享 120 秒总预算并为重试留出时间；接受单层 JSON 代码围栏，拒绝空证据和非法合同，低置信度仍需确认。同一附件识别失败可重试，成功结果重放不重复调用模型。另修复模型路由仅在调用前检查预算的问题：在途调用也受剩余总预算约束，超时取消并记录失败。
- **命令面板**：真实浏览器验收发现 Portal 内容缺少定位和层级，被遮罩拦截点击。已补固定定位、正确 z-index 和独立主题变量，加入课程切换点击回归；该次等待发生在切课操作，不能误记为模型延迟。
- **跨版本会话恢复**：真实闭环发现刷新只保存会话 ID、没有保存课程版本。已持久化所选版本，恢复时先对照当前用户的课程范围校验，再读取会话状态/复核；不再向默认大纲版本请求教材会话。
- **学习主题保持**：通用的“继续学习”操作会带上持久化迁移题和科学任务类型参与检索；排除 UI 操作词、单字符及纯数字。目录过滤兼容页首罗马数字/页码，避免 `viii / Contents` 被当成正文。相关性检查针对实际引文，且英文词带边界，防止片段别处的主题词或 `eV` 命中 `Every` 后展示无关开头。来源正文、引文和哈希均不改写。
- **代码输出合同恢复**：真实模型曾输出单引号 Python 字典，数值虽与参考一致，解析后仍缺失指标，正确返回 INCONCLUSIVE。现在缺失指标也进入已有的最多两次修复预算，并明确要求 `json.dumps`；不宽松解析、不拿参考值填补、不扩大执行限制。最终仍需真实执行与确定性校验通过。
- **完成态与教学权威**：完成/中断后清除可提交迁移卡；旧 TypeScript 教学写入及查询路由统一返回 410，学生主路径继续使用 Python API。遗留库仍用于离线回归。
- **全新环境构建**：去掉触发 401 的 Dockerfile frontend 拉取，提供 `compose.registry.yaml` 与 `make build-registry / up-registry`，使用 Docker 官方 ECR 基础镜像。PostgreSQL 镜像从固定版本及 SHA-256 校验的 pgvector 源码构建。已完成 `--pull --no-cache` 和独立空卷栈启动；API/Web/数据库/Redis/Neo4j/沙箱全部健康，迁移到 0008，pgvector 0.8.6，空库课程数为 0。独立验证栈已停止，卷保留；主环境数据未删除。
- **扫描修正**：密钥扫描不再把 `flask-*` 图标文件名里的 `sk-` 子串误判为密钥；合成的带引号和裸密钥仍会触发失败。
