# 有限方势垒课堂试用与教师操作规程

本规程用于可复现的小规模课堂试用。`finite-barriers@1.0.0` 是版本化教学设计，
不是已经取得课堂成效的证明，也不表示任何教师已批准其内容。仓库中的脚本、假网关测试、
浏览器测试和真实模型测试均不能替代真实教师评阅或学生独立作答。

## 角色、范围与开课前检查

实际执行者应在试用记录首页填写课程、年级、授课语言、日期、参与人数、设备条件、
任课教师、技术负责人、测评安排，以及是否允许教材、计算器、同伴交流或外部 AI。
不要预填“学生已掌握”“教师已批准”或不存在的参与人数。

| 步骤 | 必须由谁实际执行 | 留存材料 |
|---|---|---|
| 确认教学适用性和来源 | 任课教师 | 已发布课程资料、页码、适用条件、纠错记录 |
| 审定题目和评分量规 | 任课教师；建议另一位教师复核 | 题目版本、参考解释、量规及真实审定意见 |
| 配置课程成员和权限 | 学校授权管理员 | 教师/助教/学生的课程成员关系 |
| 说明数据用途并征求参与意愿 | 实际组织教师及学校负责人员 | 告知文本、必要的同意或退出记录、保管责任人 |
| 进行首答、重构、独立测评 | 实际学生 | 未经辅助的原始作答，不由脚本代写 |
| 判断作答并记录教学决定 | 实际任课教师 | 判断依据、量规等级、下一轮追问 |

技术负责人先按 [LOCAL_STACK.md](LOCAL_STACK.md) 启动服务、运行迁移到当前 head，
确认包含 `0009` 请求幂等、`0010` 教师复核和 `0011` 执行预算迁移。导入资料后仍须经过既有审阅与发布流程；
导入本身不会发布。检查学生只能访问自己的学习记录，助教可读取本课程教学轨迹，
教师/课程管理员才可提交本规程中的教学决定。

部署时将 `BUILD_REVISION` 设置为构建所用的完整 Git 提交 SHA。未配置时导出显示 `unknown`，
不能在报告中补写为未经核实的版本。保存模型路由配置的非敏感说明；不要把令牌、
服务密钥、密码或填充后的 `.env` 放入试用记录、截图或仓库。

## 教学包与评价标准

完整待审材料见 [独立测评包 1.0.0](../teacher-packets/finite-barriers-heldout/1.0.0/README.md)：
前测、即时测和延迟测三份各 8 题的学生题本，分开的教师参考推导、量规锚点及 12 个对照例。
它们未用于此前模型提示调优。它们是待实际教师审阅和预测试的草案，尚未证明三份题目等值。
教师须预先决定使用全卷还是材料中约定的核心题，不要把下文的简短课堂承诺时长当作全卷测评时长。
该仓库是公开的，`teacher-only` 文件名不能防止学生读到答案；实际教师须检查暴露情况、
控制分发或另选私有等值题，并预登记处理方法。后续向模型展示过的题目不得继续当作未见题。

旧教学设计 `finite-barriers@1.0.0` 的摘要保持不变。新 `1.1.0` 明确区分独立提交条件、
数值正确、解释推断和掌握程度；试用前显式选择并记录版本，既有过程不会被自动换包。
`assessment_evidence.valid_independent_submission` 即使为真，也不代表物理答对。
`numeric_correctness` 与 `explanation_assessment` 分项保存；自动 `mastery_status` 始终为
`not_assessed`。教师的真实量规判断另行归属到教师本人，不能由旧 `verified` 标志推算补齐。

教学包定义见
[`course_packages.py`](../../services/api/quantum_agent/teaching/course_packages.py)。
每个包包含固定 ID、版本、内容 SHA-256、学习目标、阶段任务和量规。修改题目或量规时发布新版本，
不要直接替换旧版本的含义。已固定教学包的学习过程应继续使用该版本；换包另建学习过程。

| 学习目标 | 对应量规 | 可观察表现 |
|---|---|---|
| FB-O1：解释禁阻区非零指数解 | FB-R1 | 区分经典禁阻与波函数严格为零，给出理由 |
| FB-O2：连接边界连续性和概率流 | FB-R2 | 说明边界条件如何决定振幅，T 如何由概率流比定义 |
| FB-O3：预测宽度趋势并检查数值可信性 | FB-R3 | 指明固定条件，解释趋势，辨识数值下溢与近零误差 |
| FB-O4：独立应用和迁移 | FB-R4 | 新题首答在应用内辅助锁定时提交，首答和后续修订分开保存 |

量规等级为 `meets`（达到）、`partial`（部分达到）、`needs_revision`（需修订）、
`not_assessed`（未评阅）。不得把未评阅计为不合格或通过。教师须在判断依据中说明学生的原文、
相应量规 ID 和为何达到或未达到。模型的概念分析只能作为候选意见；
确定性参考计算通过也不代表学生答案正确。

本包的核心科学条件是：一维、静态、实有限方势垒、质量恒定、左右自由区势能相同。
“宽度增加使 T 减小”的任务限于固定 `0<E<V0`、固定高度和质量。
不能把这一陈述无条件推广到势垒上方的干涉/共振情形。左右波数不同时，透射率还需要概率流因子。
有限宽度的亚势垒透射可极小但严格为正；浮点下溢到零不能作为“无隧穿”的物理论据。
科学工具报告 `inconclusive` 时应记录限制并由教师决定进一步检验，不能改写成通过。

教师还应核查模型候选诊断的物理措辞：固定 `E、V0、m` 时 `κ` 与衰减长度 `1/κ` 均不变，
增大的是势垒宽度和经过的衰减路程。不要把模型的“更长衰减长度”等不精确转述当作科学结论。
本次真实模型合成评价已记录此类措辞问题；自动契约通过不能替代这一步实际教师检查。

## 可复现的课堂流程

以下时长仅是排课建议，应在试用前固定实际安排，不能在看到结果后更改成功标准。

1. **教师准备与预登记（真实教师，课前）。** 选定教学包版本，发布适当来源，
   审定前测题 A、即时独立题 B 和延迟题 C。三题考查相同目标但更换参数或表征，
   不应仅把刚显示的答案复制到新题。预先写明允许工具、作答时间、缺交处理、
   量规判定方式、计划比较的指标和延迟测评日期。
2. **未经辅助的前测/初始承诺（真实学生，建议 5 分钟）。** 在展示解释、参考计算或同伴答案前，
   收集题 A 的预测、理由和可选信心。可询问“有限方势垒的亚势垒透射是否严格为零，为什么”，
   但不得在题干中先给出答案。系统承诺门保存学生的初始表达；教师另行组织的前测也保留原稿与题号。
   不让学生事后用改正答案替换初稿。
3. **最小干预和有依据追问（真实学生参与，建议 10 分钟）。** 围绕当前学生原句追问依据与检验方法，
   保存干预文本和来源链接。课程图中的先修边只表明相关主题；缺少某一步或请求帮助，
   都不能据此断定学生缺少先修知识。有引文支持的先修困难仍是候选判断，需要教师核实。
4. **修订、参考实验与解释（真实学生，建议 10 分钟）。** 学生先修订预测或推理，再运行允许的计算。
   保存科学请求参数、结果、验证状态与限制。工具核验了指定科学命题或参考计算，
   不是对全份解答或掌握程度的认证。设备失败、模型不可用和错误重试均留在记录中。
5. **Teach-Back 重构（真实学生，建议 5–8 分钟）。** 学生用自己的话连接指数解、边界连续性、
   概率流和条件化宽度趋势。保存首次重构、模型候选分析、追问与后续澄清。
   “流程进入下一阶段”只表示满足当前流程规则，不等于教师认可或科学证明。
6. **有支架迁移后进入 Solo（真实学生，建议 8 分钟）。** 完成当前迁移要求后再开启独立任务。
   学生应先独立提交题 B。后端锁定应用内辅助，并保存与任务 ID 关联的
   `solo_first_attempt`；后续反馈和重试不得覆盖此首答。报表分开显示首次表现、
   重试次数及重试后表现。退出 Solo 记为中止，不计为独立通过。
   首答错误后再改正属于修订成功，不计为首次独立通过；Solo 仍激活时不显示参考数值。
   应用内锁定无法观察手机、外部 AI 或同伴帮助；是否满足课堂独立作答条件须由现场教师记录。
7. **教师复核并改变下一步（真实教师）。** 在教师轨迹页查看原答、引用、干预、修订和独立首答，
   按量规给出依据。选择继续、要求修订或核实先修概念，后两者必须写出具体追问。
   下一次符合条件的普通教学轮会采用该追问；独立测评、承诺门和已存在的阶段要求优先，
   教师指令不会解锁 Solo 或跳过要求。检查后续结果中 `teacher_follow_up.review_id`
   确实链接该决定。没有该链接时不要声称教学决定已经应用。
8. **延迟独立测评（真实教师和学生，建议一周内预先指定的时间）。** 由教师发放题 C，
   明确关闭辅助并监督独立完成，再按同一版本量规复核。
   当前应用没有自动排课、外部监考或完整延迟测评模块，应将题 C 原稿和教师评分单作为独立材料，
   用匿名学生 ID、课程、题目版本和本次 conversation ID 关联，不伪装成系统自动观察。
9. **导出与复核（教师/技术负责人）。** 导出每个完整学习过程及题 A/C 的外部测评材料，
   核对时间顺序、版本、任务关联、首答、干预、修订和真实教师决定。保留所有失败、未完成和退出情形，
   同时记录不能评价的原因。

## 教师界面与接口

登录有本课程权限的账号，打开 `/teacher/traces`，选择课程和课程版本，再打开对应教学轨迹。
页面上方“待人工复核”队列也显示尚无完成 trace 的首轮暂停。先检查拟议响应、来源与验证，
填写实际理由后批准或拒绝；响应丢失时使用“重试同一复核决定”，保留原 interrupt ID 与理由。
该操作恢复实际执行；不能用脚本点击记录冒充教师已审阅。
“教师判断依据”必填；选择“要求修订作答”或“核实先修概念”时填写下一轮具体追问
（最多 1000 字符）。只对学习过程固定教学包中的量规评分。
活动教学轮尚未结束或上一条追问尚待应用时，新的决定会返回冲突；先完成或恢复该流程并刷新记录。
网络中断后先读取已有决定，避免重复提交不同判断。

实际 API 均要求已认证的课程权限。下列路径中的 course、edition、conversation、turn ID
来自当前账号允许访问的记录，不能用任意学生 ID 替代：

| 操作 | 接口 |
|---|---|
| 读取可用包与完整目标/量规 | `GET /api/v1/courses/{course}/editions/{edition}/teacher/course-packages` |
| 创建/继续学生教学轮 | `POST /api/v1/courses/{course}/editions/{edition}/teaching/turns` |
| 读取教师决定 | `GET /api/v1/courses/{course}/editions/{edition}/teacher/conversations/{conversation}/reviews` |
| 记录教师决定 | 同一路径 `POST`；仅教师/课程管理员 |
| 导出证据链 | `GET /api/v1/courses/{course}/editions/{edition}/learning-records/{conversation}/export` |

通过接口显式选择教学包时，教学轮请求增加：

```json
{"course_package":{"package_id":"finite-barriers","version":"1.0.0"}}
```

显式方势垒科学请求也会选用该包。旧学习过程可能没有包引用，不能事后补称其采用了当前量规。
浏览器只发送允许的能力 ID，服务商和模型配置留在服务端。
重试同一教学轮须使用相同 `client_request_id` 和相同输入；改写作答应生成新请求 ID。
Solo 作答必须携带当前 `transfer_task_id`。缺失或不匹配时只记录“未评价”，
不会展示参考结果、计为失败或记为独立表现；旧客户端须刷新/升级后带当前任务标识重新提交。

教师决定示例仅展示接口格式，**不是实际教师意见**：

```json
{
  "source_turn_id": "填写实际已完成教学轮的 UUID",
  "decision": "revise",
  "reason": "填写教师依据学生原文所作的实际判断，并引用量规编号",
  "follow_up": "request_revision",
  "probe": "填写实际需要学生回答的一个具体问题",
  "criterion_ratings": {"FB-R2": "needs_revision"}
}
```

决定和学习证据保留为追加记录，后续修订使用新记录；不要直接改写历史。
`solo_first_attempt` 是当前独立任务的状态快照，不是所有任务的数组。
正常开启新任务时该快照会重置，旧任务首答仍保存在追加的 `SOLO_ATTEMPT` 证据与历史教学轮中。
当前课堂流程按一个学习过程完成一轮闭环组织；不要把不同任务的首答混为同一测评。
预发布 HITL 的批准/拒绝/编辑与本节的教学复核是两类事件。
批准一条限定范围的输出不等于批准整个教学包，也不等于学生已经掌握课程。

## 超时、恢复和执行成本

默认每个教学轮的累计活动时间上限为 180 秒，最多 12 次实际模型 HTTP 请求；
重试、路由回退和恢复共享同一本持久化账本，不能通过换工作进程刷新额度。
人工复核等待另记为 `human_wait_seconds`，不消耗活动时间。
`stage_timings` 和报告到的用量可在导出的 `execution_budget` 中检查；
保守预留 token 单位不是供应商计费 tokenizer，用量缺失须保留为未知。

网络断开或未收到结果时，保留输入并点击“检查保存状态”；先恢复已保存结果或待复核状态，
需要重放时再使用同一请求标识。额度耗尽的轮次保留为失败；恢复记录后由学生明确发起新轮，
不要把重发次数计为独立首次作答。执行前已保存的 `submitted_request` 只证明提交了什么，
不证明通过任务关联、独立性、科学正确性或掌握评价。

配置、受控模型耗时及适用范围见
[延时和预算实测](evidence/classroom-20261020/latency-and-budgets.md)。
模型服务排队或计算仍可使一次调用持续数十秒；有界超时和恢复是试用流程的一部分，
不能承诺每次在短时间内得到解释。

## 证据核对与分析

导出格式为 `classroom-evidence/1.0.0`。逐个核对下列链条，而不只展示最终正确答案：

`学生初答/承诺 → 有来源的干预 → 学生修订 → Teach-Back → 新任务的 Solo 首答/重试 → 教师决定 → 后续教学动作`。

导出的 `turns`、`events`、`learning_state.solo_first_attempt`、`teacher_decisions` 及其 ID
提供关联基础。记录的 `provenance` 包含代码提交、工作流版本、教学包版本/摘要、
文档版本/来源摘要以及实际记录到的模型任务、路由配置标识和模型别名。
模型供应商可能更新同一别名对应的权重，因此别名并不保证模型输出逐字可复现。
每轮版本记录最多保留 128 条模型调用和 16 段暂停/恢复执行版本；达到上限时，不能用该列表长度推断总调用量，须结合单独的运行日志和供应商用量记录。
历史记录未保存的版本信息保留为未知，不能推测补齐。
保存的教学输出不证明浏览器已经接收或学生已经阅读；网络中断时应结合恢复记录和现场观察核实。

下载文件包含 `record_sha256`。按 UTF-8 对 `record` 做 `sort_keys=True`、
`ensure_ascii=False`、紧凑分隔符 `(',', ':')` 的 JSON 规范化后计算 SHA-256 可复核文件变化。
该摘要不是数字签名，不能证明操作者身份或现场无外部帮助。
单过程导出有轮次、事件数和字节预算；超限返回 413，不能把截断材料当作完整证据链。
学生仅能导出自己的记录，且 Solo 期间辅助资料访问受锁定；教师可执行本课程监督。

建议报告以下可核对指标，并同时给出分母、缺失值和记录来源：

- 题 A、题 B **首次**独立答案及题 C 的各量规等级；与多次重试后的结果分别统计。
- 每个学生的干预次数、修订次数、Solo 重试和退出次数；教师是否实际评阅、追问是否实际应用。
- 从发起到完成/失败的延时、科学工具耗时、模型调用数、失败恢复次数和无法评价的原因。
- 软件可用性问题及学生/教师实际反馈。满意度不替代学习表现。

技术性能可通过相同脚本重复测量；课堂表现必须来自实际学生。
描述性试用只能说明此样本中的观察变化，不能证明 AI 导致学习提升。
若需比较效果，由实际教学研究团队预先设计等值题、基线、比较条件、分组方式、样本量、
盲评和缺失处理；不应在看到结果后挑选成功样例或自行宣称因果效果。
建议由第二位教师独立评阅预先约定的一部分匿名答案，记录一致情况和分歧解决过程，
不能自动生成第二位教师的认可。

## 数据保管、退出与证据标签

试用前指定数据负责人和保存期限，并按学校既有要求执行告知、同意、访问和退出流程。
界面账号 UUID 仍可能与个人对应，原始自由文本也可能含姓名或联系方式；导出不会自动匿名化。
研究/竞赛材料使用独立的试用编号，身份对照表单独限制访问。
分享前由负责人员检查自由文本、截图和附件并删除无关个人信息。
只收集所需学习资料，不把服务密钥或完整凭据写入日志。

说明谁能读取原始数据、谁能读取匿名材料、保存到何日、如何处理退出和归档。
数据库追加保护用于维护证据历史，当前没有一键匿名化或全生命周期删除界面；
到期处理和删除请求须由负责管理员依据已确定的流程实施并核对备份/外部导出副本。
不能仅删除浏览器下载文件后声称原始数据已删除。

所有展示材料明确标注以下来源之一：

| 标签 | 可以证明什么 | 不能替代什么 |
|---|---|---|
| 脚本演示 / 假模型自动化测试 | 固定输入下的软件行为、权限或恢复契约 | 真实学生表现、教师意见 |
| 真实模型自动化评价 | 指定配置和输入下的模型/系统输出与成本 | 真实课堂成效、现场独立性 |
| 实际课堂观察 | 实际参与者在已说明条件下的作答和决定 | 未采用研究设计时的因果效果 |

尚未执行的课堂步骤标为“待实际教师/学生执行”。没有真实参与数据时，
提交教学设计、软件验证结果、限制和本规程即可，不填写虚构成绩、满意度或教师批准。
